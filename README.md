# SpotiApp 2.0

Локальное веб-приложение для подготовки DJ-сетов из плейлистов Spotify. Начиная с версии 2.0, SpotiApp запускается в Docker и открывается в браузере под названием Setcrate. Экспорт содержит MP3 320 кбит/с CBR, плейлист M3U8 и CSV со статусом каждой позиции.

## Запуск на ПК

1. Запусти Docker Desktop в режиме Linux-контейнеров и открой терминал в папке проекта.
2. Если файла `.env` ещё нет, создай его из `.env.example`. Для импорта CSV и JSON ключи не нужны.
3. Выполни `docker compose up -d --build`.
4. Открой [Setcrate](http://127.0.0.1:8765). Если изменил `SETCRATE_PORT`, используй новый порт.

Сайт доступен только на этом ПК. Web и аудиоворкер используют один образ и общий том `setcrate-data`. Воркер работает без сетевого доступа. Том хранит исходники, результаты и очередь. `docker compose down` останавливает приложение. Удаление тома удаляет хранящуюся в нём медиатеку и настройки.

## Spotify

Создай или открой приложение в [Spotify Developer Dashboard](https://developer.spotify.com/dashboard). Укажи Redirect URI `http://127.0.0.1:8765/auth/spotify/callback` с фактическим портом сайта. Внеси Client ID в `SPOTIFY_CLIENT_ID` и выполни `docker compose up -d`. Затем нажми **Подключить Spotify** на сайте. Для Development Mode нужен Spotify Premium у владельца приложения, а аккаунт должен иметь доступ к приложению и плейлисту. Для входа используется PKCE. Client Secret Spotify приложению не нужен.

Альтернативный импорт принимает Spotify Playlist JSON из выгрузки аккаунта и CSV в UTF-8. Если в JSON несколько плейлистов, укажи точное название. Поля CSV `title,artist` обязательны. Можно добавить `album,isrc,duration_ms`.

## Подготовка и экспорт

Чтобы убрать плейлист из списка Setcrate, открой его и нажми **В корзину**. Для возврата открой **Корзину** в списке плейлистов и нажми **Восстановить**. Это действие выполняется в Setcrate. Аудиофайлы продолжают очищаться по обычным срокам хранения. Повторный импорт неизменившегося плейлиста Spotify открывает существующую активную копию.

После импорта по ссылке Spotify Setcrate автоматически запускает поиск для всего плейлиста. Для уже импортированного плейлиста и CSV / JSON используй кнопку **Автопоиск**. Очередь хранится в SQLite и продолжает работу в фоне.

Автопоиск проверяет Hitmos, PromoDJ, Internet Archive и Openverse. Для PromoDJ используются публичные кнопки скачивания. Internet Archive используется для записей с открытой лицензией и доступным оригинальным файлом. Если задан `JAMENDO_CLIENT_ID`, Setcrate также проверяет Jamendo. Точное совпадение может перейти в **Готово** автоматически. Правдоподобные записи с другим миксом, отличающейся длительностью или расхождением в тегах доступны в **На проверке**.

В статусе **На проверке** можно прослушать до трёх скачанных вариантов. Выбери один кнопкой **Подтвердить версию**, даже если в метаданных есть расхождение. Трек перейдёт в статус **В работе**, затем в **Готово** и будет отмечен для ZIP. Кнопка **Ни один не подходит** переводит трек в статус **Нет файла**.

Галочка **ZIP** справа управляет включением готового трека. Готовые треки отмечены по умолчанию. Исключённый трек остаётся доступен для предпрослушивания и отмечается в CSV. Когда очередь завершится, кнопка **ZIP** выдаст отмеченные треки и полный отчёт с источниками. Покрытие зависит от доступности записей в онлайн-каталогах.

1. Импортируй плейлист и добавь файлы кнопкой **Аудиофайлы**. Можно загрузить несколько файлов или прикрепить файл к конкретному треку.
2. Для отсутствующих треков открой поиск по артисту и названию в Beatport, Bandcamp или SoundCloud. Скачай покупку либо оригинал, который автор разрешил скачать, и добавь этот файл. При наличии ключей SoundCloud в `.env` сайт также показывает результаты официального поиска прямо в карточке трека. Получение файла выполняется на сайте источника.
3. Раскрой позицию, прослушай и подтверди версию. Расхождения по ISRC, версии и длительности остаются видимыми рядом с кандидатами. Ранее принятый файл можно автоматически использовать для той же записи. Исходники пониженного качества требуют отдельного подтверждения.
4. Дождись статуса **Готово**. Обработка измеряет интегральную громкость, применяет постоянный gain к копии и проверяет MP3 после кодирования. Цель −14 LUFS, потолок −1 dBTP. При большом пик-факторе трек может остаться тише. Статус и измерения видны в карточке и CSV.
5. Нажми **ZIP**. Распакуй архив целиком в постоянную папку. В rekordbox выбери **File → Import → Import Playlist** и укажи `playlist.m3u8`. Если rekordbox не разрешит относительные пути к файлам, импортируй папку `Tracks` и проверь порядок по отчёту.

## Скачивание на сервер и очистка

В карточке трека вставь прямую HTTPS-ссылку на аудиофайл, опубликованный магазином, артистом или лейблом для загрузки, и нажми **Скачать файл**. Setcrate загрузит файл размером до 180 МБ и проверит метаданные. Подтверди версию перед обработкой. Ссылки на страницу, плеер или поток нужно сначала открыть на площадке и получить файл через её интерфейс.

Опционально добавь `JAMENDO_CLIENT_ID` в `.env`. Кнопка **Скачать с Jamendo** ищет единственное совпадение по названию, артисту и длительности и скачивает файл, если артист разрешил загрузку. Проверь версию и условия использования конкретной записи на Jamendo.

ZIP удаляется после отправки. Готовые MP3 можно повторно скачать в течение часа после экспорта. По истечении этого времени Setcrate удаляет их и освобождает исходники, которые больше не нужны другим трекам. Временные файлы и неиспользуемое аудио очищаются через 24 часа. Плейлисты и список позиций сохраняются. После очистки для нового экспорта добавь исходники снова.

## Проверка на твоём компьютере

- Возьми свой Spotify-плейлист из нескольких треков. Добавь точную версию одного из них, другой микс второго и оставь третий без файла.
- Прослушай несколько кандидатов, выбери один или нажми **Ни один не подходит**. Проверь, что в M3U8 попал только выбранный готовый файл, а CSV содержит строки для всех треков.
- Импортируй распакованный M3U8 в свою версию rekordbox. Проверь порядок, теги и воспроизведение файлов. Сведи пару треков и послушай, насколько комфортна разница громкости.
- Если что-то не загружается, посмотри `docker compose logs --tail=100 web worker`.
